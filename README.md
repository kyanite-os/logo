# Le logo de Kyanite

[Kyanite](https://github.com/kyanite-os) est une image Linux immuable
fondée sur Fedora bootc, avec KDE Plasma : minimale et durcie.

Son logo est un **K taillé dans un bloc de kyanite** — le minéral bleu
dont le projet tire son nom, qui pousse en cristaux allongés en lames.
